# Enterprise endpoint troubleshooting
Illustrative workflows based on support experience; no confidential data or unverified outcomes.

## Windows instability
- Establish scope, frequency, recent changes and data backup status.
- Review Reliability Monitor and System event logs; correlate timestamps.
- Check storage, drivers and update history. Use approved DISM/SFC procedures where appropriate.
- Validate stability and document findings or escalate with evidence.

## Secure connectivity client failures
- Capture error codes and identify affected networks and users.
- Check connectivity, DNS, client service status, version and installation logs.
- Coordinate approved repair or redeployment with security administrators; never bypass controls.
- Confirm access to authorized resources and record results.

## Engineering application failures
- Reproduce the issue, compare working endpoints and review application logs.
- Verify supported application/OS versions, dependencies and permissions.
- Coordinate with application owners; validate a representative workflow after remediation.
