# Infrastructure home lab — planned project
Goal: demonstrate systems administration in an isolated virtual environment.

1. Build a Windows Server evaluation VM and Windows client VM on an isolated virtual network.
2. Configure AD DS and DNS; create test organizational units and users.
3. Join the client to the test domain and apply a limited Group Policy.
4. Document IP addressing, DNS resolution, authentication and policy validation.
5. Add a Linux VM and practice SSH, permissions and service monitoring.
6. Capture sanitized screenshots and publish test results after completion.

Success criteria: domain login, DNS resolution and policy application verified; recovery procedure documented. No production credentials or networks.
